# Контекст проекта EngVocabular

Дата: 2026-10-19

## Статус
- Проект — статическое приложение для изучения английских слов.
- Словарь содержит 1827 слов.
- Изученные слова сохраняются в `localStorage` и синхронизируются с GitHub через `data/progress.json`.
- Исправлено сохранение прогресса: добавлена UTF-8-кодировка JSON и отображение ошибок GitHub API.
- Каждому слову добавлена часть речи: глагол, существительное, прилагательное, предлог и другие типы.
- Часть речи отображается на карточке под английским словом.
- Глаголы и модальные глаголы выбираются с весом 2, остальные слова — с весом 1.

## Изменённые файлы
- `index.html` — отображение части речи и диагностика синхронизации.
- `dictionary.js` — третье поле у каждой записи с частью речи.
- `style.css` — оформление подписи части речи.
- `data/progress.json` — текущий сохранённый прогресс.

## Точка остановки
Функциональность добавлена: все 1827 записей имеют часть речи, а глаголы появляются в два раза чаще остальных слов.
